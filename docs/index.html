VitalsDeck

Сверхлёгкий киберпанк-мониторинг для macOS. Реальная температура CPU и GPU в строке меню, ASCII-шкалы нагрузки, режим защиты от сна Caffeine и плавающий HUD.

Скачать VitalsDeck.dmg GitHub Repository
🌡️
Температура CPU & GPU
Реальные датчики Apple Silicon без root-прав прямо в строке меню: «46°C».
📊
ASCII Телеметрия
Киберпанк-шкалы загрузки [██████░░░░] для процессора, видеоядра, памяти и сети.
☕
Режим Caffeine
Защита Mac от засыпания в 1 клик во время компиляции, рендера или долгих загрузок.
⚡
Process Terminator
Мгновенное завершение самых прожорливых процессов с защитой системных служб.
🪟
Плавающий HUD
Виджет поверх всех окон с авто-магнитом к углам экрана и под чёлку дисплея.
🚀
< 0.6% CPU Нагрузка
Нативные системные вызовы ядра macOS C libproc. Не сажает батарею MacBook.
